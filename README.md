# JavaScript Advanced - Week 4

This project contains the JavaScript Advanced practice tasks
completed during my internship.

## Topics Covered

- Local Storage
- JSON
- API Fetch
- Form Validation
- ES6
- const and let
- Arrow Functions
- Array filter()

## Practice Questions

### 1. Local Storage

Stores the user's name in browser localStorage and displays
the name even after refreshing the page.

### 2. Email Validation

Validates an email address using JavaScript and Regular Expression.

### 3. API Fetch

Fetches a random quote from a free API and displays it on the webpage.

API used:

DummyJSON Quotes API

### 4. Arrow Function and Filter

Uses an ES6 arrow function with the `filter()` method to find
numbers greater than 50.

## Technologies Used

- Fetch API
